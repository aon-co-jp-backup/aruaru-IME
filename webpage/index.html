aruaru-IME

画面の文脈から入力モードを予測してライブ変換するAI日本語IME。日英の相互翻訳、郵便番号→住所、人名・地名辞書つき。

An AI IME that predicts the input mode from screen context and converts live. Japanese-English translation, postal-code to address, people and place dictionaries.

特長 / Features

  • Mozc辞書+Viterbiによる変換、JMdictによる日英の相互翻訳。 Conversion with the Mozc dictionary and Viterbi, Japanese-English translation via JMdict.
  • 郵便番号(ハイフン有無どちらも)から国名・住所を候補表示。 Postal code (with or without hyphen) to country and address candidates.
  • 人名・有名人・地名・駅名・花の名前の辞書を既定で搭載、毎朝のデータ更新。 Built-in dictionaries of people, places, stations and flowers, refreshed every morning.
  • Windows / macOS / Linux(fcitx5・ibus) / Android。 Windows / macOS / Linux (fcitx5, ibus) / Android.
